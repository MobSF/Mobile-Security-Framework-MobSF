Requirements for ZIP-based project uploads

MobSF supports iOS and Android (Eclipse and Android Studio) project files uploaded as ZIP archives. Each project type has specific structural requirements described below.

Eclipse Project

The file AndroidManifest.xml and the directory src/ must exist in the root directory of the zipped source files.

/ AndroidManifest.xml / src/

Android Studio Project

AndroidManifest.xml must be located at app/src/main/AndroidManifest.xml and the directory app/src/main/java/ must exist.

app/src/main/AndroidManifest.xml app/src/main/java/

iOS Project

The .xcodeproj file must exist in the root directory of the zipped source files.

/ YourProject.xcodeproj
